Configure the meter the way the customer wants it

For the sales team. Choose the sensor type, size and materials, the transducer with its interface module, the certificates and the project data; the sheet on the right updates as you go and lists the document package for the bid. The configuration code follows the manufacturer's published ordering table (rev. 2019/02); where the table is silent the tool says so instead of guessing.

1 Sensor type

2 Sensor size and materials

3 Transducer, interface and outputs

4 Certificates and documents

5 Project and service data

6 Commercial data and deviations

7 Documents

Each document is generated from the configuration above. Click to view; "Download PDF" saves the file. Certificates are specimens: the signed originals are issued by the manufacturer with the serial number.
